# 独立工具路由、会员与题库接通设计

## 需求与边界

- 修复账号重复、长账号挤压、模型名称乱码并移除 DeepSeek。
- 22 个工具保留首页和导航入口，但不再显示编号目录；每个工具拥有可复制、可前进后退的 `/tools/<id>` 路由。
- 延续错题网红金品牌，采用参考站的胶囊顶栏、短文案卡片、明确箭头和三列到单列响应式骨架，不复制对方商标与图片。
- 会员资料只展示昵称；邮箱、手机号和统一认证的合成域名不直接暴露。
- Mogan 兼容 LaTeX、RAG、母题匹配和用户资料上传贯穿同一条分析链。公开题库必须保留来源与版权状态。
- 以 24 份数学/英语文本化整卷作为回归基准；真实手写 OCR 另行以用户上传卷面验证，不把文本基准冒充 OCR 准确率。

## 架构决定（ADR）

### ADR-01：保留单体应用，增加 History API 路由

选择在现有 Python 单体与原生前端上增加服务端 SPA fallback 和浏览器 History API。相比引入新前端框架，改动范围小、部署风险低，并能让全部工具获得独立 URL。服务端对未知工具返回 404，前端前进/后退恢复正确工作台。

### ADR-02：会员字段本地扩展，不改变统一认证主键

`app_users` 增加 `display_name`、`membership_tier` 与 `membership_expires_at`。统一认证邮箱仍作为稳定身份键，界面只使用显示名；缺少显示名时去掉 `@unified.ms1001.com` 后再省略。这样兼容旧会话，也避免账号信息撑坏布局。

### ADR-03：题库分为“可用数据”与“宣传目标”

现有 LaTeX 高考试卷作为来源明确的 RAG 文档导入；深圳初三先导入课程标准型知识包和自建基准题型。300 母题、30 年真题、每题 12 解法仍作为后续数据工程目标，不在界面伪装为已完成。

## 失败处理与验证

- 路由工具不存在时回首页并提示。
- RAG 无命中时明确标注“未使用资料”，不伪造来源。
- LaTeX 转换标记引擎和公式复核状态。
- 自动测试覆盖 22 条路由、模型清理、24 份整卷基准、会员显示和窄屏无横向溢出。
