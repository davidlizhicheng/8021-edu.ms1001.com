# 错题网学生/教师双模式界面设计

## 目标

把现有工具门户式页面改造成纯中文学习工作台。学生围绕上传、分析、训练、复习推进；教师围绕试卷、复核、学情、导出和机构管理推进。

## 信息架构

学生模式：学习首页、全卷分析、单题拆解、今日复习、错题本、学习档案。

教师模式：教学首页、全卷分析、待复核、试卷历史、学情报告、档案导出、机构管理。

两种模式共享账号、试卷、错题、八步分析、训练、掌握度、历史与导出数据。模式切换只改变导航和首页任务，不复制业务数据。

## 视觉方向

采用纸张批注式视觉：暖白纸面、深墨正文、朱红重点、金色进度。删除英文装饰标题、混合语言按钮、大面积渐变和工具矩阵。桌面端使用精简侧栏，移动端使用底部主导航。

## 状态设计

整卷任务显示等待、识别、逐题分析、完成和失败；低置信度题显示“需要确认”；空错题本提供上传入口；教师模式突出待复核数量。所有状态和操作均使用中文。
