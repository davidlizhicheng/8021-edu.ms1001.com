# AI拆博士 · 产品介绍

**主标题：** AI错题拆博士---AI中高考错题难题拆解提分博士  
**副标题：** 一个平台，装下全学段AI 学习工具箱，支持你冲击中高考。  
**域名：** https://edu.ms1001.com

---

## 一、产品定位

AI拆博士不是「拍照搜答案」工具，而是面向 K12、中考、高考场景的 **错题拆解与提分训练系统**。

核心主张：

> **错一道，拆透一类。**  
> 把一道难题拆成「题型入口 → 拆解公式 → 解题模型 → 多解路径 → 巩固变式 → 学习档案」的完整闭环。

### 与搜题类产品的差异

| 维度 | 传统搜题 App | AI拆博士 |
| --- | --- | --- |
| 用户心智 | 看答案、看解析 | 拆题、练透、过关 |
| 输入方式 | 单题拍照 | 图片 OCR + PDF/Word 上传 + 文本粘贴 |
| 输出结果 | 一题一解 | 超细拆解 + 多解 + 小诗复盘 + 三道巩固题 |
| 学习闭环 | 看完即走 | 作答 → AI 批改 → 过关移除 |
| 护城河 | 题库规模 | 拆题方法论、学习档案、工具矩阵 |

---

## 二、目标用户

1. **学生**：中高考备考、错题复盘、自主刷题  
2. **家长**：看懂孩子错在哪里、该怎么练  
3. **教师 / 教培**：备课、组卷、讲评、学情诊断（工具矩阵）  
4. **机构**：白标部署、积分兑换、后续 SaaS 扩展

---

## 三、核心功能

### 3.1 错题拆解工作台（核心）

1. 选择学科或自动识别  
2. 上传题目图片 / PDF / Word / 粘贴文本  
3. 视觉模型 OCR 识别  
4. 用户修正题干  
5. AI 输出：拆解公式、趣味比喻、解题/答题模型  
6. 一题多解 / 多视角  
7. 小诗 / 口诀逐句复盘  
8. 生成三道巩固题  
9. 学生提交答案后 AI 批改  
10. 生成错题学习卡片（可选图片模型）

### 3.3 辅助能力

- **多模型支持**：MiniMax（视觉 OCR）、DeepSeek（推理）、Fenno（GPT 中转）  
- **文件上传**：PDF、Word(.docx)、TXT、Markdown、CSV、图片  
- **用户体系**：注册登录、积分、兑换码  
- **生成历史**：拆题、批改、卡片、工具输出全记录  
- **个人档案**：按学科导出 Markdown 学习档案  
- **后台管理**：模型配置、API Key 快捷更换、提示词管理

## 四、技术架构（当前版本）

- 前端：静态 Web（HTML/CSS/JS）  
- 后端：Python 单服务 + SQLite  
- 部署：Docker + Nginx（宝塔）  
- AI：外部 LLM API（MiniMax / DeepSeek / Fenno / OpenAI 兼容）  
- 文档解析：pypdf + python-docx

适合 **Demo / 内测 / 小范围试点**，后续可升级 PostgreSQL、对象存储、任务队列与正式母题库。
