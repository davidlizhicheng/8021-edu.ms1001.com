# AI拆博士 · 商业计划书

**项目名称：** AI错题拆博士---AI中高考错题难题拆解提分博士  
**副标题：** 一个平台，装下全学段AI 学习工具箱，支持你冲击中高考。  
**编制日期：** 2026 年 6 月  
**线上地址：** https://edu.ms1001.com

---

## 摘要

AI拆博士面向 K12 至高考阶段的学习提分市场，以「错题拆解 + 巩固训练 + 学习档案」为核心闭环，叠加 21 项全科 AI 工具矩阵，服务学生、家长、教师与教培机构。

**商业模式：** SaaS 订阅 + 积分消耗 + 机构白标 + 增值服务（档案导出、学习卡片、定制提示词）。

**第一阶段目标：** 完成线上 Demo 验证，获取 500–2000 名种子用户，验证拆题完成率、巩固题过关率与付费意愿。

---

## 1. 市场分析

### 1.1 市场规模

- 中国 K12 在校生约 1.8 亿，中高考备考人群高度付费  
- AI 教育工具市场快速增长，但多数产品仍停留在「搜答案 / 讲题」  
- 错题本、变式训练、学情诊断是家长与机构的 **高频刚需**

### 1.2 痛点

| 角色 | 痛点 |
| --- | --- |
| 学生 | 看懂答案不会举一反三；不知道错在哪个步骤 |
| 家长 | 看不懂孩子错因；无法有效陪练 |
| 教师 | 备课组卷耗时长；讲评缺乏结构化工具 |
| 机构 | 缺差异化 AI 产品；难沉淀学员学习数据 |

### 1.3 竞争格局

- **搜题巨头**：题库大、流量大，但「拆题训练闭环」弱  
- **通用 AI**：泛化强，但缺 K12 拆题方法论与档案沉淀  
- **AI拆博士机会**：垂直「错题拆解粉碎机」定位 + 工具矩阵 + 可私有化部署

## 3. 商业模式

### 3.1 收入来源

1. **C 端积分包**  
   - 注册赠送体验积分  
   - 兑换码 / 微信支付购买积分包  
   - 拆题、工具运行、卡片生成按次扣积分

2. **会员订阅**  
   - 月卡 / 季卡 / 年卡：更高积分额度 + 档案导出 + 优先模型

3. **B 端机构**  
   - 私有化部署（年费 + 维护）  
   - 白标定制（Logo、域名、提示词、模型配置）  
   - 按学员 seat 收费

4. **增值服务**  
   - 定制学科提示词  
   - 学习卡片批量生成  
   - 学情报告 PDF 导出

## 4. 运营策略

### 4.1 获客渠道

- **内容营销**：错题拆解案例、小诗复盘、提分路线图（短视频 / 公众号）  
- **教师 KOL**：工具矩阵免费试用，引导班级试点  
- **家长社群**：「错一道拆一类」方法论传播  
- **SEO**：edu.ms1001.com 学科长尾词（如「高考数学错题怎么练」）

### 4.2 留存策略

- 生成历史与学习档案形成数据壁垒  
- 巩固题过关机制驱动复访  
- 兑换码与邀请奖励

### 4.3 关键指标（North Star）

- **拆题完成率**：上传 → 拆题结果成功返回  
- **巩固过关率**：三道变式题全部批改正确  
- **7 日留存**：注册后第 7 天仍使用  
- **付费转化率**：体验积分耗尽后购买比例

## 5. 技术与成本

### 5.1 当前架构成本（内测）

| 项目 | 估算/月 |
| --- | --- |
| 云服务器 2C4G | ¥80–150 |
| 域名 + SSL | ¥10 |
| MiniMax API | 按量，约 ¥200–800 |
| DeepSeek / Fenno | 按量，约 ¥100–500 |
| **合计** | **¥400–1500/月** |

### 5.2 边际成本

- 单次拆题主要成本为 LLM Token  
- 图片 OCR 与卡片生成成本高于纯文本  
- 可通过模型路由（简单题 DeepSeek，复杂题 MiniMax/Fenno）优化

### 5.3 技术演进

- 短期：SQLite + 单容器，满足内测  
- 中期：PostgreSQL + Redis 队列 + OSS  
- 长期：母题库 RAG + 用户隔离 + 审计合规

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| API 成本波动 | 多模型路由、积分定价、缓存相似题 |
